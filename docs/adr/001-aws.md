# ADR-001 — Run the lab on AWS

**Status:** Accepted

## Context

The platform needs a managed Kubernetes cluster for the cloud side, a VM to act as an edge site, a container registry and remote state for Terraform. AWS credits are available; Azure credits are not.

## Decision

Use AWS: EKS for the cloud cluster, an EC2 instance with k3s as the edge site, ECR for images and S3 for Terraform state.

## Consequences

- Costs are covered by credits; budget alarms at 30 and 60 USD guard against surprises.
- The design maps one-to-one to Azure (EKS → AKS, ECR → ACR, S3 backend → Storage Account backend, IAM OIDC → Workload Identity Federation, Security Group → NSG), so moving the Terraform to the `azurerm` provider is mostly a change of resources, not architecture.
